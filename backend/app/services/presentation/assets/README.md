# Amber Brush artwork

`amber-brush.png` is original artwork generated with the built-in ImageGen tool
for the Amber Brush presentation theme. The user's reference supplied the visual
direction: a charcoal office photograph, white handwritten headings, an amber
paint edge, and a checklist body. All titles, checklist entries, charts and tables
are added as editable content; the background contains no slide copy.

The same bundled image is served to the studio and embedded in PowerPoint,
PDF, and offline HTML exports. It does not need a remote image provider.

## Generation prompt

Use case: productivity-visual. Asset type: reusable 16:9 PowerPoint slide background, landscape 1536x864. Create a text-free background inspired by an employee sick leave report: the upper 24 percent of the canvas is a very dark charcoal (#292C31) monochrome overhead office desk photo, faint laptop keyboard, paperwork and coffee under a heavy charcoal overlay; the lower 76 percent is a perfectly flat solid golden amber (#F5A900). A broad, naturally irregular dry paint brush stroke makes the boundary across the canvas between 21 and 28 percent down, slightly rising in the middle, with sparse tiny paint flecks restricted to the boundary. Keep the top photo so subdued that white headings will be readable. Keep every pixel below 30 percent height solid uniform amber for editable text/charts. Edge to edge full bleed. No writing, text, words, logos, icons, circles, checkmarks, graphs, borders or watermark. Clean empty space throughout, reusable professional business presentation backdrop.

## Title font

Kalam Regular is bundled from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/kalam) under the included SIL Open Font License. It is used in studio, PDF and offline HTML headings. Native PowerPoint headings use Comic Sans MS, available on standard Office installations, to keep the title text editable without requiring a font installation.
